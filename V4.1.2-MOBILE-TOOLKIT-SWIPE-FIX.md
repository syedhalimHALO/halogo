# V4.1.2 — Mobile Toolkit Swipe Fix

Issue found during Netlify mobile testing:
The “Ekosistem Sokongan HaloGo Partner” toolkit rail appeared as a horizontal carousel but could not be swiped.

Root cause:
A later `business-luxury-v3` CSS rule restored `overflow: hidden` on `.biz-toolkit-panel`, overriding the earlier mobile `overflow-x: auto` rule.

Fix:
- Re-enable `overflow-x: auto` at mobile width with scoped higher specificity.
- Preserve horizontal flex rail and 176px card widths.
- Keep scroll snap.
- Enable momentum touch scrolling.
- Hide the scrollbar while preserving swipe behaviour.
- Applied through shared CSS, so both BM and English Business pages are fixed.
