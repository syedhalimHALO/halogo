## Recommended future landing pages
Do NOT create thin pages simply to target keywords. Create these only when there is enough unique, useful content:
1. `/pelan-halo-telco/` — plan comparison, eligibility, FAQs and clear CTA.
2. `/rakan-niaga-halo-telco/` — if eventually replacing `business.html`, use a 301 migration.
3. `/esim-halo-telco/` — only if eSIM content becomes substantial enough for a dedicated guide.
4. State/city location pages — only for locations with unique store information and genuinely useful local content.

## Content principles
- One clear primary intent per URL.
- Write for users first; include related search terms naturally.
- Keep important facts in visible HTML, not only inside images/animations.
- Link contextually between plans, partner, support and location pages.
- Keep plan/pricing/benefit claims synchronized with the latest approved Halo Telco information.
- Avoid unsupported superlatives such as “terbaik”, “termurah” or guaranteed-income language.
- Avoid mass-generated city/state pages with near-identical copy.
